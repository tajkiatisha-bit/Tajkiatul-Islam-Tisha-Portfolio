TAJKIATUL ISLAM TISHA — PORTFOLIO

Files:
- index.html  : website structure/content
- style.css   : design and responsive layout
- script.js   : mobile menu, scroll reveal, current year

How to use:
1. Keep all three files in the same folder.
2. Double-click index.html to preview locally.
3. Replace the # links, email address, and project details with your real links/details.
4. To add a profile photo, replace the TI circle in index.html with an <img> element.
